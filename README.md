# Toàn Vẹn · Buổi Nhìn Rõ landing page

Static HTML/CSS/JS. No framework, no build step. Upload the whole folder to any static host
(or replace the current build of marriage.toanven.vn with it).

```
index.html            landing page
dat-lich.html         booking page: form -> VietQR payment -> confirmation
assets/css/style.css  all styles (colour tokens at the top)
assets/js/main.js     sticky booking bar + Zalo click tracking
assets/js/dat-lich.js booking flow + CONFIG block to fill in
assets/img/           all images (web-ready, ~480 KB total)
```

### Form endpoint (easiest: Google Sheet)

The form POSTs these fields: `buoc` (`dang_ky` or `da_chuyen_khoan`), `thoi_gian`, `ten`, `zalo`,
`coach`, `tham_gia`, `chia_se`. Any endpoint that accepts a form POST works (Formspree, Make, Zapier, your own API).

For a Google Sheet: Extensions → Apps Script, paste this, Deploy → Web app → access "Anyone", copy the URL into `FORM_ENDPOINT`.

```js
function doPost(e) {
  const p = e.parameter;
  SpreadsheetApp.getActiveSheet().appendRow([
    p.thoi_gian, p.buoc, p.ten, p.zalo, p.coach, p.tham_gia, p.chia_se
  ]);
  return ContentService.createTextOutput('ok');
}
```
